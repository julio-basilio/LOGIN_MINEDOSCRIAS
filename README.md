🎯 Objetivo

Este projeto começou com uma simples tela de login feita em PHP, JavaScript e CSS.

A proposta é simples:

«Qualquer pessoa pode contribuir e ajudar a transformar este projeto em algo muito maior.»

Você pode:

- 🎨 Melhorar o Front-end
- ⚙️ Criar um Back-end
- 🛡️ Implementar segurança
- 🗄️ Adicionar banco de dados
- 🚀 Otimizar o código
- 🐛 Corrigir bugs

Não importa seu nível de experiência.

Toda contribuição é bem-vinda.

📦 Instalação

Clonar o projeto

git clone https://github.com/julio-basilio/LOGIN_MINEDOSCRIAS.git

Entrar na pasta

cd LOGIN_MINEDOSCRIAS

Executar

Utilize qualquer servidor PHP:

- XAMPP
- Laragon
- WAMP
- Apache
